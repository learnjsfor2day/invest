# 目标公司深扒:Physical Intelligence + 银河通用 Galbot

> 更新日期:2026-06-10
> 选这两家的理由:都是**纯 AI / Foundation Model 路线**,对量化 / 数据背景最友好(不强制要求机械 / 控制),一中一美各一家

---

## 一、为什么是这两家(选公司逻辑)

### 与你背景匹配度评估

| 维度 | Physical Intelligence | 银河通用 Galbot | Figure | Tesla Optimus | Unitree |
|---|---|---|---|---|---|
| 对量化 / 数据背景友好 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐ | ⭐⭐ |
| 是否强制机械背景 | ❌ 不强制 | ❌ 不强制 | ✅ 强制 | ✅ 强制 | ✅ 强制 |
| AI 研究氛围 | 极强(Sergey Levine 联合创始) | 强(王鹤教授) | 中-强 | 强(但偏工程)| 中 |
| 数据 / Infra 岗位多 | ✅ | ✅ | ✅ | ✅ | 中 |

**结论**:你的"纯软件 + 数据"背景在 PI / Galbot 不被歧视。在 Figure / Tesla / Unitree 都会被问"你硬件怎么搞"。

## 二、🇺🇸 Physical Intelligence(PI)— 当前最热的具身 AI 创业

### 公司基本面

| 项目 | 数据 |
|---|---|
| 全名 | Physical Intelligence(简称 PI 或 π) |
| 创立 | 2024 年初 |
| 总部 | 旧金山 |
| 员工 | ~50-100 人(2026 估算)|
| 累计融资 | $400M+(A 轮 + B 轮)|
| **最近估值** | **~$2.4B**(2024 末)|
| 主要投资人 | Jeff Bezos、Thrive Capital、Lux Capital、OpenAI、Sequoia |

### 创始团队(看人识公司)
- **Karol Hausman**(CEO)— 前 Google Brain Robotics
- **Sergey Levine**(联合创始)— UC Berkeley 教授,RL / 机器人学习 **行业最顶尖学者之一**
- **Chelsea Finn**(联合创始)— Stanford,IRIS Lab 创始,Meta Learning 开创者
- **Brian Ichter**、**Quan Vuong** 等 — Google Brain RT-1/RT-2 核心团队

> **"全明星 founder 团队"** — 你能在硅谷找到的"最强机器人 AI 学者组合"

### 产品 / 技术路线

#### Pi-0(2024 年发布)— 公司标志作品
- 通用 VLA 模型,能做 50+ 任务
- 用 1 万小时遥操作数据训练
- 跨形态(机械臂、双臂、轮式)
- **代码 + 模型权重半开源**(吸引社区)

#### Pi-0.5、Pi-π(2025+)
- 持续迭代,加入更多数据 + 更强 reasoning
- 开始接 ToB 客户

### 商业模式
- **不卖整机,只卖"AI 大脑"**
- 跟整机厂(Figure、Apptronik、Boston Dynamics 等)合作
- 类比:**机器人界的 OpenAI 或 Anthropic**
- 长期 vision:成为机器人 Foundation Model 标准

### 文化 / 工作氛围

| 维度 | 描述 |
|---|---|
| 节奏 | 快但不疯狂(比 Figure / Tesla 缓和)|
| 工作时长 | 50-60h/周 |
| 学术氛围 | **极强** — 有 Sergey + Chelsea,内部论文很多 |
| 工程氛围 | 强 — 必须能落地到真机 |
| 远程友好度 | 偏 onsite(SF),核心团队必须 on-site |
| 多元化 | 顶级学者 + 顶级工程师混合 |

### 招聘岗位类型(2026-06)

> 根据公司公开招聘 + LinkedIn 推断,具体看 [physicalintelligence.company/careers](https://physicalintelligence.company/careers)

#### 🟢 对你最友好的岗位
1. **ML Infrastructure Engineer** — 数据 pipeline、训练平台
   - 你的 Python / 工程 / 数据背景直接用
   - 学术门槛低,工程门槛中
   - 薪资 $250-400K(美元 base + equity)
   
2. **Data Engineer / Data Scientist** — 数据处理、评估、benchmark
   - 你的量化经验**完全适配**
   - 远程可能性高于其他岗
   - 薪资 $200-350K
   
3. **Robot Learning Engineer**(初级)— 跑实验,做 evaluation
   - 学术门槛中,需要 RL / PyTorch 实操
   - 薪资 $250-400K

#### 🟡 中等门槛(需要补)
4. **Applied Researcher** — 复现、评估、新方向
   - 需要顶会论文背景或开源贡献
   - 薪资 $300-500K

#### 🔴 你较难拿到
5. **Research Scientist**(全职)— 发论文路线
   - 几乎需要 PhD + 顶会论文
   - 不要先投这个

### 面试流程(美国创业典型)
1. 简历 / Recruiter 初筛(1 周)
2. Hiring manager 电话(45 min)
3. 技术面 1:Python / PyTorch / 项目讲解
4. 技术面 2:**OOD / 系统设计 / RL 知识**
5. **现场或 onsite**:多人技术 + 文化 fit + Sergey / Chelsea 偶尔参与
6. Offer:base + equity,equity 部分谈判空间大

### 准备建议(针对你的背景)
- **必备**:跑通 Pi-0 开源代码,有自己的复现 / 修改
- **必备**:LeRobot / OpenVLA 至少有 1 个 PR
- **推荐**:LinkedIn 上和 PI 现员工建立联系(1-2 个就行)
- **加分**:1 篇 blog 写"我对 Pi-0 的改进想法"

### PI 的最大风险(去之前要想清楚)
- ⚠️ 估值已经 $2.4B,**烧钱速度极快**(团队全是顶级学者,薪资高)
- ⚠️ 商业化路径还没完全跑通
- ⚠️ Sergey / Chelsea 还有学术职位,精力分散
- ⚠️ 与 Figure / Tesla 路径有重叠风险(被收购或对手挤压)

### 对你的判断:**S 级目标**
- 文化最契合"做研究 + 工程兼顾的探索者"
- 学术 + 工程兼顾,没有 PhD 也有路径
- 长期看,如果跑通就是机器人界的 OpenAI

## 三、🇨🇳 银河通用(Galbot)— 中国最纯学术派人形

### 公司基本面

| 项目 | 数据 |
|---|---|
| 全名 | 银河通用机器人(Galbot Robotics)|
| 创立 | 2023 年 |
| 总部 | 北京(中关村)|
| 员工 | ~150-200 人(2026)|
| 累计融资 | ~12 亿人民币(A+ / B 轮) |
| **最近估值** | **~70-100 亿人民币**(2025-2026)|
| 主要投资人 | IDG、美团、商汤、北汽、字节、智谱 |

### 创始团队
- **王鹤(He Wang)** — CEO,北京大学 / 斯坦福 PhD,**国内具身智能 #1 学者**
- **姚顺雨** 等 — 清华 / 斯坦福系
- **大量北大 / 清华 / 斯坦福背景**

> **"中国版 PI"** — 学术氛围最浓的中国人形机器人公司

### 产品 / 技术路线

#### Galbot G1
- 双足轮式混合形态(下半身轮式,上半身双臂双手)
- **不是纯人形** — 这是务实选择(轮式更稳、更便宜、更快商业化)
- 主打商超、零售、办公室场景

#### 模型路线
- **GraspVLA / TrackVLA** 等自研 VLA 模型
- 开源数据集 RoboMIND
- 与北大具身智能实验室深度合作

### 商业模式
- **整机 + AI 模型双轮**
- 主打商超 / 零售机器人(已有美团合作)
- 海外扩张早期

### 文化 / 工作氛围

| 维度 | 描述 |
|---|---|
| 节奏 | 中等偏快,**比 Tesla / Figure 缓和** |
| 工作时长 | 996 不强制,但氛围努力 |
| 学术氛围 | **极强** — 论文产出多,北大合作 |
| 工程氛围 | 强 — 已落地商业场景 |
| 远程友好度 | 北京为主,偶尔远程 |
| 多元化 | 主要本土人才 + 少量海归 |

### 招聘岗位类型(2026-06)

#### 🟢 对你最友好的岗位
1. **数据工程师 / 平台工程师**
   - 数据采集、清洗、标注、训练 pipeline
   - 你的量化数据背景直接用
   - 薪资 50-100 万人民币
   
2. **机器学习工程师 / 算法工程师(应用)**
   - 跑模型、评估、应用层落地
   - 学术门槛中
   - 薪资 60-120 万人民币

3. **强化学习 / 模仿学习工程师**
   - 需要 RL 实操
   - 学术 + 工程混合
   - 薪资 80-150 万人民币

#### 🟡 中等门槛
4. **VLA 模型研究员**
   - 需要顶会论文 / 强 ML 背景
   - 薪资 100-200 万人民币 + 期权

#### 🔴 较难
5. **首席研究员级别** — 通常给海归博士

### 面试流程(中国创业典型)
1. 简历筛 + 内推(强烈建议内推,提速 5x)
2. HR 电话(30 min)
3. 技术面 1:基础(Python、ML、概率)
4. 技术面 2:项目讲解 + 系统设计
5. **算法面**(LeetCode / 概率题)
6. 与王鹤或核心 PM 终面
7. Offer:base + 股权(早期员工股权可观)

### 准备建议(针对你的背景)
- **必备**:刷 LeetCode(中国面试必考)
- **必备**:复现 1-2 个开源 VLA 项目
- **推荐**:看王鹤老师的论文(NeurIPS / CoRL)
- **加分**:加入北大 / 清华具身智能 群,刷脸熟

### Galbot 的风险
- ⚠️ 估值已经偏高
- ⚠️ 中国市场对具身智能预期已 price in
- ⚠️ 商业化路径(商超机器人)是否能规模化未证
- ⚠️ 与智元 / Unitree 等竞争激烈

### 对你的判断:**A 级目标**
- 中国选项里**最学术 + 工程平衡**的
- 适合"想留在中国 + 不想 996 + 学术氛围"的人
- 王鹤是绝对的人才磁石,行业 networking 极佳

## 七、薪资 / 股权谈判要点(你的资本市场认知派上用场)

### 美国(PI / Figure / NVIDIA 类)
- **Base salary**:$200-400K
- **RSU / Equity**:占 30-50% 总 comp
- **Sign-on bonus**:$20-100K
- 谈判空间:base 通常少,equity 多
- **关注点**:vesting cliff、稀释、option vs RSU

### 中国(Galbot / 智元 类)
- **Base**:50-150 万人民币
- **股权 / 期权**:早期员工 0.05-0.5%,稀释后可能仍有可观回报
- **签字费**:相对少
- 谈判空间:base 中,期权大
- **关注点**:行权价、AB 类股、未来融资稀释

### 你的特殊优势
- 你看得懂股权和估值,**不会被忽悠**
- 用你的市场判断:**估值 / 商业化前景 / 退出路径**评估 offer
