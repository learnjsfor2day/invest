# 执行器 / 伺服电机 深度分析

> 更新日期:2026-06-10
> 价值量定位:人形机器人成本占比 30-40%,**最大单一价值环节**

---

## 一、为什么执行器是人形机器人的"心脏"?

人形机器人 = 大脑(AI)+ 小脑(控制)+ **关节(执行器)**。一台 Optimus 全身约 28-40 个关节,每个关节由一个执行器驱动。执行器决定:
- **力**(扭矩、负载)
- **速度**(移动快慢)
- **精度**(操作精细度)
- **能耗**(电池续航)
- **成本**(BoM 占比最大)

> 一个粗略数字:Optimus 单台执行器总成本约 $5,000-8,000(BoM ~$25,000),占比 20-35%。降本最大空间也在这里。

## 二、执行器分类

```
执行器 Actuator
├─ 旋转执行器 Rotary
│  ├─ 谐波执行器(谐波减速器 + 电机)
│  │  └─ 用于:肩、肘、腕等高精度小关节
│  └─ RV/行星执行器(RV 减速器 + 电机)
│     └─ 用于:髋、大腿等高扭矩大关节
├─ 线性执行器 Linear
│  ├─ 行星滚柱丝杠 + 无框电机
│  │  └─ 用于:膝、踝(伸缩动作)
│  └─ 滚珠丝杠 + 电机(老方案)
└─ 灵巧手关节执行器(微型化,见 dexterous_hand.md)
```

### 旋转 vs 线性
- **旋转执行器**:技术成熟,日系强项,Optimus Gen 1 主要用旋转
- **线性执行器**:Tesla Optimus 引入大量线性执行器(膝、踝),用滚柱丝杠 — 这是 Tesla 的关键差异化,**A 股一堆"丝杠"概念股就是吃这个**

## 三、价值链拆解

一个执行器单价 ~$200-500,内部成本结构:

| 部件 | 占比 | 卡脖子程度 |
|---|---|---|
| 减速器/丝杠 | 30-40% | 极高(见专题) |
| 无框/无刷电机 | 25-30% | 中 |
| 力矩传感器 | 10-15% | 高 |
| 编码器 | 8-10% | 中 |
| 驱动器/控制板 | 8-10% | 低 |
| 结构件/外壳 | 5-8% | 低 |

## 五、可交易标的(美股优先)

### 🥇 最直接受益:Allient (ALNT)

**地位**:中小型无框电机 + 伺服系统,客户包括 Boston Dynamics、Anduril 等。被市场视为"美股小盘人形 + 防务双弹性"标的。

**特点**:
- 市值小(~$300-500M),弹性大
- 防务订单 + 机器人订单双引擎
- 营收 $500M 量级,有机会接到人形供应链订单

**风险**:
- 小盘股流动性差
- 是否进入 Optimus 供应链尚不明朗
- 容易被题材炒作

---

### Yaskawa ADR (YASKY)

**地位**:全球伺服电机霸主。市场份额 ~25%,工业 + 人形双重受益。

**逻辑**:
- 工业机器人复苏 + 人形供应链需求
- 已与多家中国人形厂商合作

**风险**:
- ADR 流动性一般
- 日元汇率波动

---

### Nidec ADR (NJDCY)

**地位**:全球最大综合电机厂,从微型到大型电机全覆盖,正大举投资无框电机产线。

**风险**:
- 多业务稀释机器人故事
- 创始人交班期管理动荡

---

### Moog (MOG.A) — 高端伺服

**地位**:航空、防务、医疗高端伺服。与 ISRG 等医疗机器人深度合作。

**逻辑**:
- 防务驱动主业稳健
- 是医疗机器人 + 部分人形的高端供应商

---

### Parker Hannifin (PH) / Rockwell (ROK) / Emerson (EMR)

**地位**:都是综合工业巨头,机器人执行器/伺服只是其中一块。适合"基础仓配置 + 隐含机器人 beta",不适合追题材。

## 六、关键技术路线分歧

### 谐波 vs 行星 vs 摆线针轮
- 谐波:轻、精,适合上肢小关节,Harmonic Drive 垄断 70%
- 行星/RV:重、扭矩大,适合下肢大关节,Nabtesco 垄断
- 摆线针轮(中国流行):轻量化新兴方案

### 旋转 vs 线性丝杠(Tesla 路线)
- 特斯拉膝/踝大量使用**线性执行器 + 行星滚柱丝杠**
- 这是 A 股"丝杠概念股"逻辑核心
- 但其他厂商(Figure、1X)更多用纯旋转方案
- **谁的路线胜出会决定谁的供应链受益**

### 准直驱(Quasi-Direct-Drive,QDD)新势力
- 部分新兴玩家(MIT 系)用低减速比 + 高扭矩电机直驱
- 优点:控制带宽高、力反馈好
- 缺点:扭矩密度有限
- Boston Dynamics Atlas 电动版部分使用
- 这条路线如果走通,会颠覆传统减速器需求

## 八、当前(2026-06)判断

1. **执行器是人形机器人产业链最大价值池,但美股直接标的有限** — 主要受益者是日股、A 股
2. **ALNT 是美股小盘弹性最大标的,但需谨防题材炒作风险**
3. **YASKY、NJDCY 适合中长期配置,工业 + 人形双引擎**
4. **A 股汇川 / 鸣志 / 昊志的股价波动是美股投资者最重要的"中国信号"**
5. **技术路线尚未收敛**,过早下注单一公司风险高
