## 八、信号可信度分级

| 等级 | 信号来源 | 行动 |
|---|---|---|
| ⭐⭐⭐⭐⭐ | 公司官方财报 / 政府数据 / FDA | 高度可信,可按此交易 |
| ⭐⭐⭐⭐ | 主流券商深度报告、Bloomberg / WSJ 调查 | 较可信,可参考 |
| ⭐⭐⭐ | 行业协会数据(IFR、JARA) | 慢但准 |
| ⭐⭐ | 社交媒体大 V(Serenity 等) | 仅作题材判断 |
| ⭐ | A 股传闻 / 公众号 | 仅作情绪信号 |

## 九、避免常见误区

1. **不要用 A 股传闻直接交易美股** — 信息很快被 price in,但需要观察
2. **不要把题材股当 long-term holding** — 弹性大但容易杀
3. **不要忽视医疗 / 工业机器人** — 这两个赛道不靠 Optimus 故事也能走
4. **不要在季度财报前满仓** — Tesla / Figure 任何 miss 会带崩板块
5. **不要忘记看"未上市玩家"** — 一级市场是二级的领先指标

## 十、配合 pool.jsonl 的工作流

```
每周一 ──→ calendar.md 看本周关注什么
        ──→ 自选股 / Bloomberg 看价
        ──→ pool.jsonl 更新观察记录

财报季 ──→ 优先看核心 6 家(TSLA/NVDA/ISRG/SYM/TER/CGNX)
       ──→ 财报后 24 小时内写复盘

大会前 ──→ 提前 1-2 周埋伏(若有信号)
       ──→ 大会后 1 周内复盘 / 兑现

突发新闻 ──→ 先判断信号等级(本文第八节)
         ──→ 再决定是否动手
```
