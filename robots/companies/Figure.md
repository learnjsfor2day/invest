## 一、为什么 Figure 是"必看的非上市公司"?

虽然 Figure 不能直接交易,但跟踪 Figure 对美股投资者至关重要:
1. **一级估值是二级板块的领先信号** — Figure 估值跳升,A 股供应链次日异动
2. **任何重大节点(融资 / 大客户 / IPO)会直接影响 NVDA、ALNT、Sony 等关联标的**
3. **Figure IPO 可能性最大** — 一旦上市,会立刻成为机器人板块重要标的
4. **背后投资人 = 信号**:NVIDIA、Microsoft、Bezos、OpenAI(已离散)的判断

## 四、技术路线 — Helix VLA 模型

### 大事件:与 OpenAI 决裂
- 2022-2023:Figure 与 OpenAI 深度合作开发模型
- 2024 年初:Figure 02 与 GPT-4o 集成 demo 火遍 X
- **2024 年中:Figure 宣布与 OpenAI"分手"**,转自研
- 自研模型命名 **Helix**

### Helix VLA 架构
- **VLA = Vision-Language-Action**
- 视觉 + 语言指令 + 动作输出
- 端到端,模型直接输出关节运动
- 类似 Tesla 的 FSD 但用于人形

### 训练数据
- 遥操作(人类操作员控制 Figure 收集数据)
- 模仿学习(IL)
- 强化学习(RL)
- 大量 BMW 工厂真实场景数据

### 技术差异化
- **比 1X 更"工业级"** — 性能强,不软体
- **比 Tesla 更"AI 集中"** — 不必同时做车
- **比 Boston Dynamics 更"AI 原生"** — Atlas 偏经典控制

## 六、护城河 vs 风险

### 护城河
1. **顶级投资人背书**(NVIDIA、MSFT、Bezos)
2. **CEO 连续创业经验**(Brett Adcock)
3. **BMW 落地场景**(真实工厂数据)
4. **自研 Helix 模型**(避免被 OpenAI 卡脖子)
5. **专注人形**(不像 Tesla 同时做车)

### 风险
1. **估值已透支**($39.5B vs ~$50M 营收) — 任何 miss 暴雷
2. **OpenAI 离开后 Helix 独立性待证**
3. **与 Tesla 直接竞争** — 资金 + 人才烧钱战
4. **商业化路径不清晰** — 目前主要是"PR + 试点"
5. **IPO 时间不明** — 估值若长期不消化,投资人压力大
6. **关键工程师流失**(高估值 + 高竞争)

## 九、IPO 路径预测

### 触发条件(任一发生即增大概率)
1. 营收突破 $200M+(2027-2028 可能)
2. 大客户合同 + 长期订单
3. NVIDIA / Microsoft 战略持股 IPO 退出诉求
4. 估值进一步推升至 $50B+,私募融资难度增加

### 预测时间窗口
- **乐观**:2027 年底 IPO
- **中性**:2028
- **悲观**:2029+(若烧钱过快或商业化滞后)

### IPO 后预期
- 上市当日 +30-100% 是可能的
- 早期波动巨大,谨防"IPO 即顶点"
- 长期投资价值取决于商业化兑现
