# Tesla Optimus 供应链全景 深度分析

> 更新日期:2026-06-10
> 视角:抓住板块β = 抓住 Optimus 节奏与供应商定点

---

## 一、为什么 Optimus 是机器人板块的"灵魂"?

1. **唯一具备自我消化场景的整机厂** — Tesla 自家工厂就是最大客户(全球 Gigafactory 30+ 万员工)
2. **唯一具备 AI + 算力 + 整车制造三位一体的玩家**(Dojo 算力 + FSD 模型 + 机械工程)
3. **马斯克社交流量** — Optimus 任何动态自带板块β
4. **2026-2027 是兑现窗口** — 5K → 50K → 100K 台年产计划是板块判断锚

> **板块定律**:Tesla 不动,机器人板块一般也不动(指题材股)。Tesla 大涨,A 股、日股、美股小盘集体跟涨。

## 二、Optimus 演化时间线

| 版本 | 年份 | 关键变化 |
|---|---|---|
| **Bumblebee**(原型) | 2022.10 | 概念,几乎不能动 |
| **Optimus Gen 1** | 2023.03 | 11 DoF 手,能慢走 |
| **Optimus Gen 2** | 2023.12 | 22 DoF 手,自研无框电机,体重轻 10kg |
| **Optimus V3** | 2024.10 | 仿生手,关节结构升级,产线小批量 |
| **Optimus 量产版**(2026 计划) | 2026 | 5K 自用 + 部分对外销售 |
| **Optimus Gen 3**(传) | 2026 末 / 2027 | 进一步降本,目标对外 $20-30K |

## 三、核心硬件 BoM 拆解

> 以下数字基于公开拆解、UBS / 高盛 / 摩根研究报告整合,仅作 framing,不保证精确。

### 单台 Optimus 估算 BoM($25,000-$30,000 量级,2026-2027 量产初期)

| 模块 | 估算成本 | 占比 | 关键供应商 |
|---|---|---|---|
| **执行器(28-40 个)** | $5,000-8,000 | 25-30% | 自研 + Yaskawa / Nidec / 鸣志 / 兆威 |
| **减速器 + 丝杠** | $3,000-5,000 | 12-18% | Harmonic Drive / Schaeffler / 绿的谐波 / 恒立液压 |
| **电池(2.3 kWh)** | $700-1,200 | 3-5% | 自家(Tesla 4680)/ 宁德时代 |
| **灵巧手(2 只)** | $4,000-8,000 | 15-25% | 自研为主,部分外购 |
| **视觉系统** | $300-600 | 1-2% | Sony CIS、自研芯片 |
| **传感器(IMU、力矩)** | $500-1,000 | 2-4% | STM / ADI / 柯力 |
| **AI 计算(芯片)** | $800-1,500 | 3-5% | Tesla 自研 D1 衍生 |
| **结构件** | $2,000-3,000 | 8-12% | 拓普 / 三花 / 旭升 |
| **其他(线缆、电源)** | $1,000-2,000 | 4-8% | Amphenol / TE / 立讯 |

> **降本路径**:Musk 公开说 2030 年 BoM 目标 $10K,主要靠规模 + 中国供应链。

## 七、Optimus 板块 trading framework

### 进场信号
- Tesla 财报后 Optimus 上调指引
- Musk 公开发布新 demo
- 大客户合同公告(Tesla 自家工厂部署节点)
- A 股 Tesla 概念股集体异动 → 美股次日跟涨概率高

### 离场信号
- Tesla 财报 Optimus miss 指引
- 关键演示翻车(摔倒、卡住公开报道)
- A 股板块连续放量滞涨

### 个股相对强弱观察
- 若 Tesla 涨而 ALNT 不动 → 市场不认可 ALNT 进供应链
- 若 Schaeffler 持续跑赢 → 市场押注线性执行器路线
- 若 A 股谐波涨幅 > 丝杠 → 市场押注旋转执行器

## 九、风险与陷阱

1. **Tesla 自研垂直整合扩张** — 越自研,供应商利润越薄
2. **"Tesla 概念"伪信号** — A 股一堆蹭热度,真正进供应链的不到 30%
3. **Musk 时间表 0.5 折定律** — 5K 台 2026 年大概率 miss,2-3K 更可能
4. **技术路线突变** — 如 Gen 3 砍掉某零部件,相关供应商腰斩
5. **地缘风险** — 中美关系变化影响中国供应商
