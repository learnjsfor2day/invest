## 一、为什么要研究未上市玩家?

1. **一级估值是二级板块的领先信号** — Figure 估值跳升,A 股供应链次日异动
2. **IPO 路径影响美股交易机会** — 直接影响"上市后可买"的标的池
3. **技术路线分化判断** — 三家走向不同,谁胜出决定供应链格局
4. **大厂背后投资人** — OpenAI 投 1X、NVDA 投 Figure、TSLA 自研,反映 AI 巨头判断

## 三、Figure 深度

### 公司画像
- **CEO Brett Adcock** — 连续创业者(Archer Aviation 创始人)
- 总部:加州 Sunnyvale
- 员工 ~300 人(2025 年)
- 已完成多轮融资,累计 $1.5B+

### 技术路线
- **大脑**:自研 VLA 模型 **Helix**,2025 年初公开
- **历史**:与 OpenAI 合作 → 2024 年决裂转自研
- **硬件**:自研执行器、自研灵巧手 16 DoF
- **训练**:遥操作 + 模仿学习 + 强化学习
- **路线**:端到端,模型直接输出关节运动

### 商业进展
- **BMW Spartanburg 工厂**(南卡)— 2024 起部署 Figure 02 测试
- 据传与 Microsoft、UPS、英伟达数据中心讨论部署
- 计划 2026 年量产数千台

### 投资人(信号灯)
| 投资方 | 含义 |
|---|---|
| NVIDIA | AI 芯片 + 算法生态 |
| Microsoft | AI 数据中心 + Azure 算力 |
| OpenAI(已减持/离散)| 早期合作,后分手 |
| Jeff Bezos | 个人战略下注 |

### 关键风险
- 估值高($39.5B)但收入极低(可能 < $50M)
- OpenAI 离开后 Helix 模型独立性待证
- 与 Tesla 直接竞争,资金消耗战
- IPO 时间不明,大概率 2027-2028

### IPO / 上市路径
- 当前没有官方 IPO 时间
- 估值 $40B+ 已经是"Pre-IPO"级别
- 一旦上市,会吸走板块资金

## 四、1X Technologies 深度

### 公司画像
- **CEO Bernt Børnich** — 挪威人,Halodi Robotics 创始人
- 总部:挪威奥斯陆 + 加州 Sunnyvale
- **OpenAI 战略投资** — 一级市场最强信号之一
- 累计融资 $250M+

### 技术路线
- **大脑**:与 OpenAI 合作训练 Foundation Model
- **硬件特点**:**软体材料 + 关节内电机** — 安全为核心(适合家庭)
- **历史型号**:EVE(轮式)→ NEO Beta(双足消费版)→ NEO Gamma(2025 量产版)

### 商业进展
- 2024 推出 NEO Beta,2025 限量出货消费版
- 主打"家庭机器人",ToC 路线
- 价格目标 $10K-15K(消费品级别)

### 关键差异化
- 唯一明确押注**消费市场**的人形玩家
- "安全优先"设计(电机扭矩有意降低)
- 数据采集 — 用户家中收集真实场景数据

### 风险
- ToC 商业化最难(安全、价格、用例)
- OpenAI 关系是否独家?
- 体力 / 性能不如 Figure / Tesla

### IPO 路径
- 暂无 IPO 信号
- OpenAI 是否会"孵化"上市,值得关注

## 五、Unitree(宇树)深度

### 公司画像
- **创始人 王兴兴** — 上海大学硕士,90 后
- 总部:杭州
- 中国机器人"明星公司"
- 累计融资 $200M+,估值约 $1B+(2024)
- 国内估值/资本看好程度高

### 技术路线
- **早期**:四足机器人 Go1 / Go2(性价比颠覆 Boston Dynamics Spot)
- **现在**:H1 双足、G1 类人形、A1 通用平台
- **大脑**:与 NVIDIA Isaac 平台深度合作 + 自研
- **硬件特点**:自研伺服执行器(性价比高)

### 商业进展
- **G1 售价 $16K,全球最便宜消费级人形**
- 已有数千台 ToC + 科研出货
- 2025 春晚跳舞机器人破圈,知名度爆涨
- 进入海外科研市场

### 关键差异化
- **极致性价比** — 别人 $50K,Unitree $16K
- **开放生态** — SDK、ROS 兼容,开发者友好
- **品牌效应** — 中国 Boston Dynamics

### 风险
- 性能仍低于 Figure / Tesla
- ToC 用例不清,可能仍是"玩具"
- 出口管制风险(美欧潜在限制)

### IPO 路径
- 多次传闻港股 / 科创板上市
- 2026 年是较合理的窗口
- **如果上市,会成为"中国机器人板块"的旗舰股**

## 七、对二级市场投资者的意义

### 监控维度
1. **三家估值变动** — 季度新闻,直接影响板块情绪
2. **Demo 视频对比** — 谁的视频最炸,谁的 AI 真实领先
3. **投资人动作** — NVIDIA / OpenAI 加注、减持
4. **大客户合同** — BMW、Mercedes、Amazon 部署进展

### 板块映射

| 一级动作 | 二级影响 |
|---|---|
| Figure 估值上调 | 美股 ALNT、NVDA、Cognex 涨;A 股拓普三花涨 |
| 1X 消费版火爆 | 利好 Sony 视觉、消费电子链 |
| Unitree 上市 | 港股机器人板块全面重估;A 股供应链涨 |
| 三家任一翻车 | 板块 risk-off,Tesla 也带跌 |

### IPO 候选押注
- **Unitree 港股最早(2026-2027 可能)** — 提前布局港股 9880(优必选)、相关供应链
- **Figure 美股(2027+)** — 关注 NVDA 衍生标的
- **1X 美股(2028+)** — 关注 OpenAI 生态衍生
